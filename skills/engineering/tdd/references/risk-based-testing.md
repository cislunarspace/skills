# 风险优先的测试选择

当切面较多、需要决定先测什么时，用两个维度对每个切面做评估。

## 两个维度

- **失败频率**：罕见 / 少见 / 偶尔 / 常见
- **影响程度**：最小 / 一些 / 较大 / 最大

交叉点标为红（高频+高影响）、黄（任一维度中等）、绿（双低）。

## 操作

1. 列出所有候选切面
2. 对每个切面评估失败频率和影响程度
3. 标记红 / 黄 / 绿
4. 红色区域先测，黄色其次，绿色最后或不测

## 边界

| 情况 | 处理方式 |
|---|---|
| 用户明确要求全覆盖测试 | 跳过风险评估，直接全测 |
| 无法判断某个切面的风险等级 | 标为黄色，与用户确认 |
