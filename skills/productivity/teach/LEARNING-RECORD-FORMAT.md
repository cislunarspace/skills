# 学习记录格式

学习记录存在 `./learning-records/` 中，使用顺序编号：`0001-slug.md`、`0002-slug.md` 等等。惰性创建目录——只在第一条记录写入时才创建。

它们是教学中相当于 ADR 的东西：它们捕捉非显而易见的课程、关键洞见和已声明的先验知识，这些东西将引导未来的会话。它们用来计算最近发展区。

## 模板

```md
# {所学或所确立内容的简短标题}

{1-3 句话：学到了什么（或确立了什么先验知识），以及它对未来会话为什么重要。}
```

这就是整个格式。一条学习记录可以只是一个段落。价值在于记录_这个_东西现在已知了，以及_为什么_它改变了接下来要教什么——不在于填满各个小节。

## 可选小节

只在它们增加真正价值时才包含。大多数记录不需要它们。

- **Status** frontmatter（`active | superseded by LR-NNNN`）——当早期的理解后来发现是错的并被替换时有用。
- **证据**——用户如何展示了理解（回答了一个问题、完成了一个练习、引用了先前的经验）。当这个论断可能被重新审视时有用。
- **含义**——这为未来会话解锁了什么或排除了什么。不显而易见时值得记录。

## 编号

扫描 `./learning-records/` 找到现有最大的编号，加一。

## 何时写学习记录

当以下任何一条为真时写一条：

1. **用户展示了对某个非显而易见东西的真正理解**——不只是接触，而是有证据他们能正确使用这个概念。这为接下来教什么设定了一个新的下限。
2. **用户披露了先验知识**——"我已经知道 X。"记录下来，这样未来的会话不会重复教。也记录所声称的_深度_。
3. **一个误解被纠正了**——用户之前相信了某个错误的东西，现在明白了为什么。这些是高价值的：它们预测相关主题未来的绊脚石。
4. **使命因学习而改变**——用户发现他们关心的东西和原来想的不同。交叉链接到 [[MISSION.md]] 并更新它。

### 什么_不算_

- 仅仅覆盖了的材料。覆盖不是学习。等证据。
- 已经在 [[GLOSSARY.md]] 中作为术语定义简洁记录的东西。不要重复。
- 一次会话接一次会话的活动日志。学习记录不是日记——它们是决策级别的洞见。

## 替代

当一条后来的记录与一条较早的记录矛盾时（用户的理解加深了或被纠正了），把旧记录标记为 `Status: superseded by LR-NNNN`，而不是删除它。理解如何演变的历史本身是有用的信号。
